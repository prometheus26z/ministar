# MINISTAR · 미니스타

현재 버전 **v0.16.5** · [플레이](https://prometheus26z.github.io/ministar/)

테란·저그·프로토스 중 종족을 고르고 1 vs 1, 2 vs 2, 3 vs 3으로 플레이하는 모바일 자동 전투 게임입니다. 생산 구역에 건물을 지으면 정해진 병력이 주기적으로 출격합니다. 상대 종족은 무작위이며, 팀전의 각 AI는 자기 자원과 생산 건물을 독립적으로 운영합니다. 아군 AI의 생산 구역도 확인할 수 있으며, 적 생산 구역은 열람할 수 없습니다.

## 경제와 생산 기준

NudeRaider가 올린 [Desert Strike v1.0 원본](https://staredit.net/sc1db/file/1246/) `Desert Strike v1,0.scx`의 UNIx/TRIG를 사용합니다. 원본 SHA-256: `91d5acdf5770a8a95949707b7cdd4b189ce37ae2fdb08b1df2b8d02f096ec814`.

- 시작 미네랄 300, 베스핀 가스 0. UMS 초기 자원 0에서 TRIG #2의 Add 300을 적용합니다.
- 수입: 하이퍼 트리거 16사이클, Fastest 환산 약 1.344초마다 미네랄 지급. 가스 시설 0~5개는 각각 10 / 12 / 15 / 18 / 22 / 26입니다.
- 완성된 투자 시설만 수입에 반영됩니다. 최대 5개이며 리파이너리·어시밀레이터는 600, 익스트랙터는 500 미네랄입니다.
- 두 번째부터 단계별로 333 / 347 / 667 / 655 사이클(약 27.972 / 29.148 / 56.028 / 55.020초)을 기존 수입 대기시간에 한 번 추가합니다. 취소한 미완성 시설에는 적용하지 않습니다.
- 출격은 46 게임초(Fastest 약 30.67초)마다 진행하며 수입 타이머와 독립적입니다. 출격 자원 지급, 전초기지 자원 보너스, 가스 수입·소비는 없습니다.
- TECx/PTEx를 대조해 원본에서 연구 완료된 기술을 시작 시 해금합니다. 버로우·러커 연구 등 원본에서 비활성인 연구나 추가적인 기본 스타크래프트 유료 연구를 판매하지 않습니다. UPGx/PUPx의 기본 비용 사용 여부와 시작 업그레이드 상태도 출처 데이터에 보존하며 추가 업그레이드 구매는 제공하지 않습니다.

## 미니스타 전장

원본 Desert Strike 지형을 90도 회전하고 중앙을 같은 비율로 잘라 세로 전장에 맞춥니다. 전초기지는 원본 맵에 배치된 프로토스 사원의 좌표를 같은 방식으로 변환해 배치합니다. 두 진영은 종족과 관계없이 프로토스 사원과 케이다린 수정 형성부를 사용하며, 주변 고정 방어타워는 배치하지 않습니다. 전초기지는 15,000 HP, 본진은 30,000 HP이고, 전초기지가 파괴되면 본진에서 반격 병력이 출격합니다.

병력은 마린 기준 최대 8열로 출격하고 각 열을 유지하며 전초기지부터 공격합니다. 건물·다른 병력과 겹치지 않는 위치에서 생성하며, 막힌 경로와 끼임은 다시 탐색합니다. 근접 병력은 건물 외곽의 여러 접근 위치로 나뉘어 공격합니다. 유효한 교전 상대를 유지하면서 주변의 공격 가능한 위협과 실제 피격에 반응합니다. 러커는 이동할 때 잠복을 해제하고 지상 적과 교전할 때 잠복하며, 행동 불가 상태에서는 잠복 전환을 시작하지 않습니다.

메딕은 부상한 지상 생체 아군을 찾아 치료 중에는 멈추고, 치료 후 진격을 이어갑니다. 치료 거리와 회복량·에너지 소비, 벙커 탑승 병력의 개별 무기 사거리·대상·공격 주기는 OpenBW 소스를 참고합니다. 전체 Brood War 이동·전투 엔진을 이식한 구현은 아닙니다.

생산 구역은 원본 맵의 건설 가능 타일과 가스 시설 다섯 곳을 사용합니다. 건설은 원작 시간의 5%가 걸리며 종족별 건설·변태·소환 단계를 표시합니다. 건설 카드에는 자동 출격 유닛과 수량이 나오고, 출격 현황은 전장과 생산 구역에서 확인할 수 있습니다. 적 유닛도 터치해 체력과 능력치를 확인할 수 있습니다.

원본 스크립트와 검증된 이미지 자료로 아콘·다크 아콘의 본체와 에너지층, 공격 거리별 효과, 사망·시체 연출을 합성합니다. 원본 프레임·반복 진입점·효과 생성 및 종료 시점을 보존하며, 시체 표시 상한은 12초로 현재 복원된 최장 연출 11.25초를 포함합니다. 건물은 종족별 파괴 효과와 이동을 막지 않는 잔해를 남깁니다.

종족별 원곡 두 트랙을 번갈아 재생합니다. 백그라운드에서는 전투와 소리가 멈추고 복귀 후 재개할 수 있습니다. 설정과 전적은 유지하며 오프라인 캐시는 사용하지 않습니다.

### 남은 원본 연출 차이

원본 `.lo` 부착 좌표표는 아직 복원되지 않았습니다. 아콘·다크 아콘의 일부 공격 효과는 스크립트에 기록된 오프셋을 사용하며, 원본 LO 좌표까지 일치하는 것은 아닙니다. 복원 자료와 절차는 [원본 애니메이션 복원 문서](docs/original-animation-recovery.md), 검증 결과는 [후속 작업 기록](docs/LUNA-HANDOFF.md)에 정리되어 있습니다.

## 개발과 검증

Node.js 22 이상과 Python 3을 사용합니다.

```sh
npm run build
npm run audit:animations
npm test
npm start
```

http://localhost:5105 에 접속합니다. `PORT` 환경변수로 포트를 바꿀 수 있습니다. 빌드는 저장소에 포함된 체크섬 검증 묶음에서 원본 리소스와 애니메이션을 복원합니다. 별도 사용자 ZIP은 필요하지 않습니다.

브라우저 검증은 Playwright 1.56.1과 Chromium을 설치한 뒤 실행합니다.

```sh
npm install --no-save --package-lock=false playwright@1.56.1
npx playwright install --with-deps chromium
node tests/browser.cjs
node tests/original-animation-browser.cjs
```

`main` 변경은 GitHub Actions의 리소스 복원·애니메이션 감사·시뮬레이션·모바일 UI·이전 캐시 정리 검사를 통과한 후 GitHub Pages에 배포됩니다. PR에서는 같은 검사를 실행하고 실제 배포는 건너뜁니다.

- `resources/desert-strike-v1.json`: 원본 비용·수입·생산·기술·업그레이드 설정과 출처
- `resources/desert-strike-evidence.json`: 원본 섹션 및 관련 트리거의 바이트 사본
- `dist/desert-strike-data.js`, `dist/lane-rules.js`: 브라우저·시뮬레이션의 공통 규칙
- `dist/autobattle.js`: 독립 수입·가스 투자·출격·자동 교전
- `tests/desert-strike.test.mjs`, `tests/original-integration.test.mjs`: 원본 바이트·경제·생산·맵 좌표 회귀 검사
- `tools/sc_iscript.py`, `dist/animation.js`: 원본 시각 스크립트 해석과 애니메이션 합성
- `tests/original-animation-browser.cjs`: 실제 원본 이미지의 레이어·반복·공격·사망 연출 검증

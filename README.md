# MINISTAR · 미니스타

스타크래프트 리마스터 리소스를 활용한 자동 전선 RTS입니다. 현재 버전은 **v0.6.0**입니다.

**플레이:** https://prometheus26z.github.io/ministar/

## 전투 방식

양쪽 진영은 같은 종족과 대칭 배치로 전투합니다. 메인 기지와 전초기지는 언덕 위에 있고 중앙 접경은 낮은 지형입니다. 길고 넓은 물길과 절벽이 측면 통로를 막아 양 진영은 중앙의 넓은 언덕 입구를 통과합니다. 병력은 상대 전초기지를 먼저 공격하고, 전초기지가 무너지면 메인 기지로 진격합니다. 어느 한쪽 메인 기지가 파괴되면 상대가 승리합니다.

양쪽 병력은 25초마다 동시에 자동 출격합니다. 유닛은 직접 조작하지 않으며 자동으로 이동하고 공격합니다. 상대편도 같은 시작 자원과 웨이브 자원 규칙으로 생산 건물을 짓습니다. 종족별 전초기지 방어는 테란의 마린 3기와 파이어뱃 1기가 탑승한 벙커 2개, 저그의 성큰·스포어 콜로니, 프로토스의 파일런과 포토캐논 2개로 구성됩니다.

## 생산 구역

전장 왼쪽 가장자리에 붙은 **생산** 버튼을 누르면 전장과 분리된 생산 구역으로 이동합니다. 이곳은 빈 상태로 시작하며, 상대의 생산 구역과 건물은 표시하지 않습니다. 생산 구역에서는 크립 조건 없이 건설할 수 있고 프로토스 건물의 전력 조건과 선행 테크는 유지됩니다. 상단의 가스 지점 다섯 곳에 가스 건물을 건설할 수 있습니다. 가스 건물은 미네랄 500을 사용합니다. 모든 건물 건설은 원작 시간의 5%가 걸립니다.

건물마다 출격 유닛이 고정되어 있습니다. 완성된 배럭은 마린 2기, 스포닝 풀은 저글링 3기, 게이트웨이는 질럿 1기를 매 웨이브마다 보냅니다. **출격 현황**은 현재 나갈 병력만 보여 주며 설정이나 해제는 할 수 없습니다. 보급 한도나 유닛 생산 비용 때문에 출격이 건너뛰지 않습니다.

각 웨이브마다 기본 미네랄 200을 받습니다. 완성된 가스 건물 하나마다 미네랄 100과 가스 50을 추가로 받습니다. AI 난이도는 상대의 추가 건물 확장 시점을 조정합니다. 브라우저 탭이 백그라운드로 가면 전투와 모든 소리를 멈추며, 화면으로 돌아와 **전장 재개**를 누르면 이어집니다. 배경 음악은 HTML 미디어 플레이어를 사용하지 않아 휴대전화의 음악 재생 카드에 등록하지 않습니다.

## 구현

- `dist/core.js`: 전투 시뮬레이션과 유닛 전투
- `dist/economy.js`, `dist/autobattle.js`, `dist/lane-rules.js`, `dist/tech.js`: 건설·자원·테크·웨이브 규칙
- `dist/app.js`, `dist/ui.js`, `dist/index.html`, `dist/style.css`: 지도·터치·인터페이스
- `dist/rts-data.json`: 추가 원작 DAT 정의와 스프라이트 정보
- `resources/`: 원작 리소스 묶음
- `tests/`: 시뮬레이션·경제·배포 UI 점검

Node.js 22 이상에서 `npm run build`, `npm test`, `npm start`를 실행한 뒤 http://localhost:5105 에 접속합니다. 다른 포트를 지정하려면 `PORT=5106 npm start`를 사용합니다.

`main` 변경 시 GitHub Actions가 원본 리소스 묶음을 검증·복원하고 시뮬레이션과 모바일 UI 검사를 실행한 뒤 GitHub Pages에 배포합니다. Pages 설정의 Source는 **GitHub Actions**입니다. 게임은 인터넷 연결 상태에서 실행합니다.

StarCraft / StarCraft: Remastered의 그래픽·음성·음악과 상표는 Blizzard Entertainment에 귀속됩니다. 비공식 실험 프로젝트이며 원본 리소스에 대한 별도의 재배포 라이선스를 부여하지 않습니다.

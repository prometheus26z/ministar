# MINISTAR · 미니스타

현재 버전 **v0.12.0** · [플레이](https://prometheus26z.github.io/ministar/)

## 경제와 생산 기준

NudeRaider가 올린 [Desert Strike v1.0 원본](https://staredit.net/sc1db/file/1246/) `Desert Strike v1,0.scx`의 UNIx/TRIG를 사용합니다. 원본 SHA-256: `91d5acdf5770a8a95949707b7cdd4b189ce37ae2fdb08b1df2b8d02f096ec814`.

- 시작 미네랄 300, 베스핀 가스 0. UMS 초기 자원 0에서 TRIG #2의 Add 300을 적용합니다.
- 수입: 하이퍼 트리거 16사이클, Fastest 환산 약 1.344초마다 미네랄 지급. 가스 시설 0~5개는 각각 10 / 12 / 15 / 18 / 22 / 26입니다.
- 완성된 투자 시설만 수입에 반영됩니다. 최대 5개이며 리파이너리·어시밀레이터는 600, 익스트랙터는 500 미네랄입니다.
- 두 번째부터 단계별로 333 / 347 / 667 / 655 사이클(약 27.972 / 29.148 / 56.028 / 55.020초)을 기존 수입 대기시간에 한 번 추가합니다. 취소한 미완성 시설에는 적용하지 않습니다.
- 출격은 46 게임초(Fastest 약 30.67초)마다 진행하며 수입 타이머와 독립적입니다. 출격 자원 지급, 전초기지 자원 보너스, 가스 수입·소비는 없습니다.
- TECx/PTEx를 대조해 원본에서 연구 완료된 기술을 시작 시 해금합니다. 버로우·러커 연구 등 원본에서 비활성인 연구나 추가적인 기본 스타크래프트 유료 연구를 판매하지 않습니다. UPGx/PUPx의 기본 비용 사용 여부와 시작 업그레이드 상태도 출처 데이터에 보존하며 추가 업그레이드 구매는 제공하지 않습니다.

## 미니스타 전장

건물이 파괴되면 원작 종족별 폭발·소멸 효과를 표시하고 잔해를 남깁니다. 잔해는 이동·건설을 막지 않으며 건물 본체를 반투명하게 남기지 않습니다. 미사일 터렛은 별도 회전 포탑 34프레임을 표시합니다. 상단·하단은 원작 콘솔 프레임과 아이콘을 쓰는 금속 패널로 구성합니다.

전장·터치 조작·자동 교전·테크 선행 조건은 미니스타 방식을 유지합니다. 중앙 저지대와 상하 고지를 넓은 경사로가 연결하고 측면 물길이 우회를 막습니다. 전초 방어시설을 먼저 파괴한 뒤 메인 기지로 진격합니다. 병력은 마린 기준 8열로 출격하며 각 열의 가로 위치를 유지합니다. 본진·터렛과 겹치지 않는 위치에서 생성하고, 아군 전초 방어선을 우회한 뒤 각 열로 복귀합니다. 경로가 끊기거나 이동 명령을 잃은 병력은 진격 경로를 다시 받습니다.

생산 구역의 육지는 원래 크기의 너비 80%, 높이 60%이며 여백은 물입니다. 건설은 원작 시간의 5%가 걸리고 테란 건설 단계, 저그 변태, 프로토스 소환 텍스처를 표시합니다. 벙커는 병력별 무기 사거리·대상·공격 주기를 검사한 뒤 공격 효과와 사운드를 출력합니다. OpenBW의 탑승 사거리 계산(무기 사거리 +64, 마린 U-238 별도)을 기준으로 하며 벙커 자체 반경을 추가 사거리로 더하지 않습니다. 선택 체력바 너비는 기존의 85%입니다. 적을 터치하면 아군 명령 선택과 분리하여 체력바를 표시합니다. 건설 카드에는 출격 유닛과 수량이 표시되며, 출격 현황은 전장과 생산 구역 모두에서 확인할 수 있습니다.

종족별 원곡의 앞·뒤 두 트랙을 번갈아 재생합니다. 백그라운드에서는 전투와 소리를 멈추며 복귀 후 전장 재개를 눌러 이어갑니다. 설정과 전적은 유지하며 오프라인 캐시는 사용하지 않습니다.

## 개발과 검증

Node.js 22 이상: `npm run build`, `npm test`, `npm start` 후 http://localhost:5105 에 접속합니다. `PORT` 환경변수로 포트를 바꿀 수 있습니다. `main` 변경은 GitHub Actions의 시뮬레이션·모바일 UI·PWA 이전 검사를 통과한 후 GitHub Pages에 배포됩니다.

- `resources/desert-strike-v1.json`: 원본 비용·수입·생산·기술·업그레이드 설정과 출처
- `resources/desert-strike-evidence.json`: 원본 섹션 및 관련 트리거의 바이트 사본
- `dist/desert-strike-data.js`, `dist/lane-rules.js`: 브라우저·시뮬레이션의 공통 규칙
- `dist/autobattle.js`: 독립 수입·가스 투자·출격·자동 교전
- `tests/desert-strike.test.mjs`: 원본 바이트 대조 및 경제·생산 회귀 검사

StarCraft / StarCraft: Remastered의 그래픽·음성·음악과 상표는 Blizzard Entertainment에 귀속됩니다. Desert Strike 원본 맵은 NudeRaider의 작품입니다. 비공식 실험 프로젝트입니다.

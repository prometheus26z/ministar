# MINISTAR · 미니스타

스타크래프트 리마스터 원본 리소스로 만드는 모바일 RTS입니다. 현재 버전은 **v0.2.0**입니다.

**플레이:** https://prometheus26z.github.io/ministar/

## 기지에서 시작하는 RTS

작전 시작 시 실제 전장에 선택한 종족의 본진(커맨드 센터 / 해처리 / 넥서스)만 배치됩니다. 시작 자원은 미네랄 50, 가스 0이며, 일꾼은 본진에서 직접 생산합니다. 저그 해처리는 애벌레 3마리로 시작합니다. 기존 병력 구매창, 추천 편성, 환불 버튼, 60초 편성 단계와 5분 제한은 제거했습니다.

- 본진·생산 건물 선택 → 하단 **생산 / 명령** → 유닛 생산. 자원·보급과 생산 시간이 적용됩니다. 대기열은 최대 5개이며 취소 시 자원을 돌려받습니다.
- 일꾼 선택 → **건설 / 명령** → 건물 → 지도에서 위치 지정. 배치 유령과 가능/불가 표시가 나오며 선행 건물, 시야, 지형, 건물 겹침, 전력과 크립을 검사합니다.
- 일꾼 선택 후 미네랄 또는 완성된 가스 건물을 터치하면 채취합니다. 일꾼이 자원과 본진 사이를 왕복해 자원을 반환합니다. 생산 건물의 집결 지점을 자원에 지정할 수도 있습니다.
- 테란: SCV가 건설 장소까지 이동해 작업하며, 작업 중단·사망 시 건설이 멈춥니다. 다른 SCV로 재개할 수 있습니다. 머신샵·컨트롤 타워 등의 부속 건물은 실제 생산 건물에 부착되어 있어야 합니다.
- 저그: 드론이 건설 위치에 도착하면 건물로 변태합니다. 해처리·레어·하이브마다 애벌레가 최대 3마리까지 생성되며, 저글링·스커지는 한 에그에서 2마리씩 나옵니다. 레어·하이브·그레이터 스파이어와 가디언·디바우러·러커 변태를 구분합니다.
- 프로토스: 프로브가 소환을 시작한 뒤 다른 일을 할 수 있습니다. 전력이 필요한 건물은 파일런 범위 안에 건설해야 하며 전력 상실 시 생산·연구가 멈춥니다.
- 보급은 서플라이 디포·오버로드·파일런과 본진에서 제공하며 최대 200입니다. 선행 건물은 완성되어야 다음 단계가 열립니다. 상위 저그 건물은 하위 단계의 선행 조건도 만족합니다.
- 스팀팩·시즈 모드·은폐·러커·스톰 등의 기술은 해당 건물에서 연구해야 사용할 수 있습니다. 합체 유닛은 해당 템플러 2기를 선택해 합체합니다.

## 테크트리

건물의 비용·HP·실드·건설 시간과 유닛 생산 시간은 확보한 원작 DAT에서 가져옵니다. 건물·생산·기술 선행 조건은 `dist/tech.js`에서 관리합니다. 예: 배럭 → 팩토리 → 스타포트, 팩토리의 부착된 머신샵 → 시즈 탱크, 게이트웨이 → 사이버네틱스 코어 → 로보틱스/스타게이트, 스포닝 풀 → 레어 → 퀸즈 네스트 → 하이브.

대조 자료: Blizzard StarCraft Compendium의 [테란 기본 건물](https://classic.battle.net/scc/terran/bbuild.shtml), [테란 고급 건물](https://classic.battle.net/scc/terran/abuild.shtml), [저그](https://classic.battle.net/scc/zerg/bbuild.shtml), [프로토스](https://classic.battle.net/scc/protoss/bbuild.shtml), [애벌레](https://classic.battle.net/scc/zerg/units/larva.shtml), [프로브](https://classic.battle.net/scc/protoss/units/probe.shtml).

## 전술 조작

유닛 터치로 선택, 더블 터치로 화면 안의 같은 종류 선택, 빈 땅 길게 누른 뒤 드래그로 범위 선택합니다. 스와이프로 지도 이동, 두 손가락으로 확대·축소합니다. 명령·생산 메뉴가 열리는 순간 시뮬레이션이 **0.5배속**, 명령 완료·취소 시 **1배속**입니다. 선택·카메라 조작만으로는 느려지지 않습니다. Ctrl → 1~9·0으로 부대를 지정하고 숫자로 호출합니다. PC에서는 M/A/P, H/S, Ctrl+숫자, F2, Space, Esc를 지원합니다.

## 실행 / 배포

Node.js 22 이상에서 `npm run build`, `npm start` 후 http://localhost:5105 로 접속합니다. 다른 포트는 `PORT=5106 npm start`처럼 지정합니다. 게임 실행에는 별도 npm 패키지가 필요하지 않습니다.

`main` 변경 시 GitHub Actions가 두 리소스 묶음의 SHA-256을 검증·복원하고 `npm test` 및 실제 Chromium 모바일 조작 검사를 실행한 뒤 Pages에 배포합니다. Settings → Pages → Source는 **GitHub Actions**입니다.

게임은 인터넷 연결 상태에서 실행합니다. 오프라인 저장 기능은 없으며 이전 서비스 워커·MiniStar 전용 캐시는 정리합니다. 설정·전투 기록은 보존합니다.

## 리소스 / 구현

- `dist/core.js`: 전투 시뮬레이션
- `dist/economy.js`, `dist/tech.js`: 자원·생산·건설·선행 조건
- `dist/app.js`, `dist/ui.js`, `dist/index.html`, `dist/style.css`: 지도·터치·UI
- `dist/rts-data.json`: 추가 원작 DAT 정의와 소형 스프라이트 프레임 정보
- `resources/assets-*.b64`, `resources/manifest.json`: 기존 리소스 묶음
- `resources/rts-*.b64`, `resources/rts-manifest.json`: 추가 원작 건물·애벌레·자원 스프라이트 묶음
- `tools/build.mjs`: 두 묶음 검증·복원
- `tools/import-rts.py`: 확보된 리마스터 원본 묶음에서 추가 데이터·리소스 변환
- `tests/`: 기존 전투 및 자원·건설·테크트리·모바일 조작 검증

정글 전장 1개와 3개 난이도, 고정된 적 진영을 제공합니다. 원작 엔진 전체의 재현은 아닙니다. 크립·전력 범위의 모양, 건설 시각 효과, 이동·충돌, 고저차, 무기·방어 업그레이드, 일부 건물 고유 기능, 캐리어/리버 내부 생산과 독립 투사 유닛 등은 아직 단순화되었거나 미구현입니다. 멀티플레이는 없습니다.

StarCraft / StarCraft: Remastered의 그래픽·음성·음악과 상표는 Blizzard Entertainment에 귀속됩니다. 비공식 실험 프로젝트이며 원본 리소스에 대한 별도의 재배포 라이선스를 부여하지 않습니다.

# MINISTAR · 미니스타

스타크래프트 리마스터 원본 리소스를 사용하는 모바일 세로형 전술 RTS의 첫 플레이 버전(v0.1.1)입니다.

**플레이:** https://prometheus26z.github.io/ministar/

종족을 선택하고 제한된 자원으로 병력을 편성한 다음, 적 커맨드 센터를 파괴하세요. 건설·채취·멀티플레이는 없습니다.

## GitHub Actions와 Pages

`main`에 변경을 올리면 Actions가 원본 리소스 묶음의 SHA-256을 확인하고 복원한 뒤, 시뮬레이션·서버 테스트와 390×844 모바일 브라우저/PWA 테스트를 실행합니다. 통과하면 `dist`를 GitHub Pages에 배포합니다. Settings → Pages → Source는 **GitHub Actions**로 선택합니다.

원본에서 변환한 이미지·오디오·초상화는 `resources/assets-*.b64`에 분할 보관합니다. `resources/manifest.json`이 순서와 체크섬을 관리하고, `npm run build`가 별도 외부 서버 없이 `dist/assets`로 복원합니다. 스프라이트는 웹 전송을 위해 원본 프레임의 크기·배치를 유지한 WebP 품질 85로 압축했습니다. 원본 소스 패키지는 별도 보관합니다.

## 로컬 실행 / Termux

Node.js 22 이상이 필요하며 게임 실행에는 npm 패키지 설치가 필요하지 않습니다. 저장소를 받은 폴더에서:

```sh
npm run build
npm start
```

http://localhost:5105 로 접속합니다. Termux에서는 먼저 `pkg install nodejs`를 실행합니다. `bash start.sh`도 같은 서버를 실행합니다. 다른 포트는 `PORT=5106 npm start`처럼 지정합니다.

## 조작

- 준비 60초 / 미네랄 1,200 / 가스 600 / 보급 30. 테란 13종, 저그 12종, 프로토스 14종을 구매할 수 있습니다. 추천 편성, 선택 환불, 시작 지역 드래그 배치를 제공합니다.
- 유닛 터치: 선택. 빠른 더블 터치: 화면 내 같은 종류 선택. 빈 땅 길게 누르고 드래그: 범위 선택. ‘범위’ 버튼을 켜면 즉시 드래그 선택.
- 빈 지면 스와이프: 카메라 이동. 두 손가락 이동·핀치, 확대/축소 버튼과 미니맵도 지원합니다.
- Ctrl → 숫자: 현재 선택을 해당 부대로 지정. 숫자: 부대 호출. 같은 숫자 두 번: 부대 위치로 화면 이동. 1~9와 0까지 총 10개입니다.
- 명령 메뉴를 여는 순간 전투 시간이 **0.5배속**이 됩니다. 목적지/대상을 지정하거나, 즉시 명령을 실행하거나, 취소하면 **1배속**으로 복귀합니다. 선택과 카메라 조작만으로는 느려지지 않습니다.
- 이동·공격 이동·지정 공격·홀드·정지·패트롤과 유닛별 특수 명령을 사용합니다. 전투 중 구매와 환불은 차단됩니다.
- 게임 내부 시간 5분 안에 적 커맨드 센터를 파괴하면 승리합니다. 아군 전멸 또는 시간 초과는 패배입니다.
- PC: M/A/P 이동·공격·패트롤, H/S 홀드·정지, Ctrl+숫자 부대 지정, F2 전체 선택, Space 일시 정지, Esc 취소.

## PWA / 오프라인

첫 화면에서 **오프라인 준비**를 눌러 완료를 기다린 후 브라우저 메뉴에서 **앱 설치 / 홈 화면에 추가**를 선택합니다. 캐시가 모두 준비되어야 이후 인터넷 없이 플레이할 수 있습니다. 설정·전투 기록·편성 프리셋은 브라우저 저장소에 보관됩니다. 오디오 채널별 음량을 설정에서 조절할 수 있습니다.

## 검증과 현재 범위

```sh
npm test
```

기본 검증은 구매/환불/보급, 10개 부대, 명령별 시간 배율과 이동/투사체, 경로 탐색, 전투 중 구매 잠금, HP·실드, 탐지, 승패, 파일 경로 및 로컬 서버를 확인합니다. Actions에서는 실제 Chromium을 설치해 모바일 UI와 `/ministar/` 경로에서의 서비스 워커·전체 캐시 후 오프라인 새로고침도 검사합니다.

정글 돌파 전장 1개와 3개 난이도를 제공합니다. 원작 엔진의 완전한 재현은 아니며 가감속·회전·충돌·고저차, 캐리어/리버의 내부 생산과 독립 투사 유닛, 일부 기술의 대상/지속시간/시각 효과, 애니메이션 스크립트 처리를 단순화했습니다. 업그레이드 연구는 없고 기술을 바로 사용합니다. Android 실기기의 다중 터치와 설치·성능은 별도 검증이 필요합니다.

## 코드 위치

- `dist/core.js`: 전투 시뮬레이션과 명령
- `dist/app.js`: 화면·터치·렌더링·오디오
- `dist/index.html`, `dist/style.css`: 모바일 UI
- `dist/sw.js`, `dist/manifest.webmanifest`: 오프라인 캐시·PWA
- `tools/build.mjs`: 리소스 체크섬 확인·복원
- `tests/`: 게임·서버·모바일 브라우저 검증
- `.github/workflows/pages.yml`: 검증 후 자동 배포

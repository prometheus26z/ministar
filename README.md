# MINISTAR · 미니스타

스타크래프트 리마스터 리소스를 활용한 자동 전선 RTS입니다. 현재 버전은 **v0.4.0**입니다.

**플레이:** https://prometheus26z.github.io/ministar/

## 전투 방식

양쪽 진영은 같은 종족과 대칭 배치로 전투합니다. 양쪽에 메인 기지와 중앙 전초기지가 있고, 기지는 언덕 위에 자리합니다. 맵 양쪽 가장자리에는 물길이 흐릅니다. 전장 중앙은 낮은 지형이며, 대부분의 가로 폭을 차지하는 넓은 경사로로 양 진영이 진입합니다. 어느 한쪽 메인 기지가 파괴되면 상대가 승리합니다.

양쪽 병력은 같은 주기로 자동 출격합니다. 유닛은 직접 조작하지 않으며 자동으로 이동하고 공격합니다. 상대편도 시간에 따라 생산 건물을 짓고 병력을 출격시킵니다. 종족별 전초기지 방어는 테란의 마린 3기와 파이어뱃 1기가 탑승한 벙커 2개, 저그의 성큰·스포어 콜로니, 프로토스의 파일런과 포토캐논 2개로 구성됩니다.

## 생산 구역

전장 왼쪽의 **생산** 버튼을 누르면 별도 생산 구역으로 이동합니다. 이곳에서만 건물을 건설하고 자동 출격 병력을 편성할 수 있으며, 오른쪽의 **전장** 버튼으로 전투 화면에 돌아옵니다. 건물 건설 시간은 원작의 10%로 줄였습니다. 건물이 완성되면 기본 유닛을 25초마다 반복 출격하며, 예를 들어 스포닝 풀은 저글링 3기, 배럭스는 마린 2기, 게이트웨이는 질럿 1기를 보냅니다.

미네랄과 가스는 자동으로 들어오며, 원작의 종족별 선행 건물·전력·크립·연구 조건을 적용합니다. 연구 가능한 기술은 편성된 병력이 전투 중 자동으로 사용합니다. AI 난이도는 상대 자원 수입과 추가 병력에 영향을 줍니다.

## 구현

- `dist/core.js`: 전투 시뮬레이션과 유닛 전투
- `dist/economy.js`, `dist/autobattle.js`, `dist/tech.js`: 건설·자원·테크·반복 출격
- `dist/app.js`, `dist/ui.js`, `dist/index.html`, `dist/style.css`: 지도·터치·인터페이스
- `dist/rts-data.json`: 추가 원작 DAT 정의와 스프라이트 정보
- `resources/`: 원작 리소스 묶음
- `tests/`: 시뮬레이션·경제·배포 UI 점검

Node.js 22 이상에서 `npm run build`, `npm test`, `npm start`를 실행한 뒤 http://localhost:5105 에 접속합니다. 다른 포트를 지정하려면 `PORT=5106 npm start`를 사용합니다.

`main` 변경 시 GitHub Actions가 원본 리소스 묶음을 검증·복원하고 시뮬레이션과 모바일 UI 검사를 실행한 뒤 GitHub Pages에 배포합니다. Pages 설정의 Source는 **GitHub Actions**입니다. 게임은 인터넷 연결 상태에서 실행합니다.

# MINISTAR · 미니스타

스타크래프트 리마스터 리소스를 활용한 모바일 자동 전선 RTS입니다. 현재 버전은 **v0.3.0**입니다.

**플레이:** https://prometheus26z.github.io/ministar/

## 전투 방식

양쪽 진영은 같은 종족과 시작 조건으로 대칭 전장을 사용합니다. 각 진영에 메인 기지, 중앙 쪽 전초기지와 방어 타워가 배치됩니다. 양쪽 병력은 첫 출격 후 **25초마다 동시에** 생성되어 자동으로 진군하고 전투합니다. 먼저 상대의 메인 기지를 파괴하면 승리합니다.

플레이어는 유닛을 직접 조작하지 않습니다. 생산 건물을 선택해 자동 출격 유닛을 지정하고, 건설·테크트리·연구로 병력 구성을 바꿉니다. 건물 건설 비용은 지불하지만, 완성된 생산 건물은 정해진 출격 주기마다 지정한 병력을 반복해서 생성합니다. 병력은 생산 건물 앞에서 나와 중앙 전선을 향해 자동 이동하고, 적 병력과 방어 시설을 공격합니다.

미네랄과 가스는 자동으로 들어옵니다. 원작의 종족별 생산 건물·선행 건물·전력·크립·연구 조건을 적용합니다. 전투 기술은 연구 후 유닛이 자동으로 사용합니다. 아군과 AI는 같은 시작 자원과 전장 배치를 사용하며, AI는 시간이 지나면서 생산 테크와 보급을 확장합니다. 난이도는 AI의 자원 수입과 추가 출격 수에 영향을 줍니다.

모바일 화면 하단의 **건물 건설**, **자동 생산**, **연구** 메뉴를 사용합니다. 맵 스와이프와 핀치로 카메라를 움직이고 확대할 수 있으며, **우리 본진**과 **전선 보기** 버튼으로 주요 위치를 오갑니다. 직접 유닛 선택·이동·공격 명령, 부대 지정, 명령 메뉴 슬로모션은 없습니다.

## 구현

- `dist/core.js`: 전투 시뮬레이션과 유닛 전투
- `dist/economy.js`, `dist/autobattle.js`, `dist/tech.js`: 건설·자원·테크·반복 출격
- `dist/app.js`, `dist/ui.js`, `dist/index.html`, `dist/style.css`: 지도·터치·인터페이스
- `dist/rts-data.json`: 추가 원작 DAT 정의와 스프라이트 정보
- `resources/`: 검증된 원작 리소스 묶음
- `tests/`: 전투·경제·배포 UI 점검

Node.js 22 이상에서 `npm run build`, `npm test`, `npm start`를 실행한 뒤 http://localhost:5105 에 접속합니다. 다른 포트를 지정하려면 `PORT=5106 npm start`를 사용합니다.

`main` 변경 시 GitHub Actions가 원본 리소스 묶음을 검증하고 복원한 뒤 시뮬레이션·모바일 UI 검사를 실행하고 GitHub Pages에 배포합니다. Pages 설정의 Source는 **GitHub Actions**입니다. 게임은 인터넷 연결 상태에서 실행합니다.

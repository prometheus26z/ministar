## Corrections to supplied plan

- Building permission comes from PUNI, prices and source names from UNIx/STR, and production groups from TRIG. A 600-mineral cost field does not make a building purchasable when PUNI denies it.
- CreateUnitWithProperties byte +27 is count; uint32 +20 is property index. Marine=6, Academy=1 Firebat+1 Medic, Vessel=1, Lurker=2. Tank count is 3 on both sides; property indices differ (4 versus 8), not counts.
- Spawning Pool bonus thresholds are Force1/team 0=6 (#275/#276) and Force3/team 1=8 (#246/#247). The bonus count is 6; below the threshold each pool outputs 5.
- Gas delays are one-shot additive SetDeaths actions (#89–100), not reset timers. No income is paid during adjustment.
- Original production is in shared team territory. The map has no per-player exclusive build rectangle. Our 33×19 upper-left crop is an explicit 1v1 adaptation, not a claimed original limit. Buildable cells in the crop: 606. Source CV5 bit 0x80 plus all 16 VF4 walkable minitiles decide placement.
- The production crop retains original orientation/footprints to avoid rotating SC building sprites and gas footprints; battlefield alone rotates left→bottom. This is an explicit presentation exception.
- Countdown uses 46 game seconds; current 46/1.5 wall time is provisional. No original-engine play/replay measurement was available. Hyper cycles are 84 ms at Fastest. This unresolved timing calibration must not be reported as measured.
- Construction remains the established MiniStar 5% construction timing; original engine build timing is not claimed.
- Source nuclear proxy ownership and civilian BOOM commands are excluded explicitly; lane UI does not expose those engine commands.
- Runtime combat keeps existing SC1 stats/weapon engine. UNIx unit HP/shield/armor overrides are applied in lane mode; full original upgrade/weapon-damage parity still needs engine comparison. The fixed objective HP values and the projected paid-defense positions are MiniStar adaptations. Broodling special replaces each snapshot enemy with one broodling (the source creates a sentinel in addition to units moved into battle).
